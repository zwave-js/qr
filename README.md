# Z-Wave JS SmartStart QR Code Generation Utility

Interactive web-based utility to generate SmartStart QR codes for Z-Wave devices.

## Usage

Visit https://zwave-js.github.io/qr

## Contributing

AI tools may assist contributors only when a human reviews, understands, and
can explain every change. Autonomous-agent contributions and unreviewed AI
communications are prohibited. See the [AI policy](./AI_POLICY.md) for the full
requirements.
